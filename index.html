PROJECT : Birthday Gift Arcade ROYAL EDITION (7,310 Lines) AI PIPELINE : Gemini Argon · Claude Sonnet 5.5 · Antigravity STACK : Three.js · WebAudio · Glassmorphism

🎁 코딩 한 줄 직접 안 짜고 AI 3종(Gemini Argon · Claude · Antigravity)으로 7,310줄짜리 '3D 생일 선물 아케이드 웹앱' 완성한 썰 (feat. 실전 프롬프트 총정리)

친구의 생일(10월 17일)을 맞아 평범한 기프티콘 대신 평생 기억에 남을 특별한 선물을 주고 싶었다. 그래서 기획한 것이 바로 스마트폰으로 직접 조이스틱을 움직여 캡슐을 뽑고, 슬롯머신을 돌리고, 3D 도감과 업적을 모으는 「3D 생일 선물 기프트 아케이드 웹앱」이다.

놀라운 점은 이 프로젝트가 Three.js 실시간 3D 그래픽 + Web Audio API 자체 합성 효과음 + 물리 가챠 & 슬롯머신 게임이 모두 들어간 약 7,310줄짜리 단일 HTML 파일인데, 내가 직접 코드를 읽거나 타이핑하지 않고 오직 AI들에게 디렉팅과 스크린샷 피드백만 주며 완성했다는 것이다.

SUMMARY 01 · 3-AI PIPELINE

🧠 왜 AI를 하나만 안 쓰고 3종(Gemini Argon · Claude · Antigravity)을 조합했을까?

5,000줄이 넘어가는 대규모 3D 웹앱은 단일 AI만으로는 용량 제한·환각(할루시네이션)·메시지 한도에 부딪힙니다. 각 AI의 장점만 결합한 3단계 파이프라인으로 한계를 돌파했습니다.

STEP 01 · GOOGLE GEMINI PRO (+ ARGON HIGH)

아이디어 구체화 & 5,400줄 뼈대 생성

초반 기획과 수천 줄의 초안 코드를 거침없이 생성. 단, 5,000줄 이상에서 출력 잘림이나 할루시네이션이 발생하므로 '초안 생성'까지만 전담.

STEP 02 · CLAUDE SONNET 5.5 (FREE PLAN)

먹통 코드 심폐소생술 & 디자인 성형

현시점 코딩 오류 복원 최강 AI. 잘린 <head>·three.js·집게 물리 로직을 변수명 역추적으로 단 1회 무료 한도 내에 완벽 복원.

STEP 03 · GOOGLE ANTIGRAVITY (PC IDE)

7,310줄 최종 고도화 & 브라우저 시각 검증

PC 로컬 파일 전체를 직접 읽고 수정하며 Argon 4와 Claude 모델을 선택 호출. 백그라운드 헤드리스 브라우저로 화면 검수까지 수행.

PART 02 · WHY GITHUB PAGES

🌐 2. 왜 굳이 'GitHub(깃허브)'에 등록해서 작업했을까?

코드를 짰는데 왜 내 컴퓨터에서만 보지 않고 매번 GitHub에 올리고 GitHub Pages로 등록했을까? 여기에는 4가지 결정적인 이유가 있다.

  1. 실제 모바일(스마트폰) 환경에서의 실시간 테스트: 생일 선물 앱은 결국 친구가 스마트폰으로 열어볼 앱이다. PC 화면에서 마우스로 누르는 것과, 실제 폰 화면에서 손가락으로 조이스틱을 밀고 버튼을 연타할 때의 터치감, 화면 비율, Web Audio 사운드 출력은 완전히 다르다. GitHub Pages에 올려두면 언제든 내 폰으로 접속해 실제 환경 그대로 테스트할 수 있다.
  2. '스크린샷 피드백'을 위한 가장 빠른 다리: 코드를 직접 읽지 않고 개발하려면 눈으로 결과를 확인해야 한다. GitHub에 코드를 올리면 1분 만에 웹 링크에 반영되므로, 폰으로 들어가서 이상한 부분을 스크린샷으로 찍어 AI에게 바로 던져주는 초고속 피드백 루프를 돌릴 수 있다.
  3. 서버 비용 0원 & 클릭 한 번으로 열리는 선물 링크: 복잡한 서버 호스팅 비용을 낼 필요 없이, 단일 index.html 파일 하나만 GitHub 저장소에 올리면 무료로 평생 유지되는 웹사이트 주소(https://아이디.github.io/...)가 생긴다. 생일 당일 친구에게 카카오톡으로 링크 하나만 보내주면, 앱 설치 없이 누르는 순간 화려한 3D 인트로가 시작된다.
  4. 안전한 버전 관리 (언제든 되돌리기 가능): AI가 코드를 고치다가 가끔 멀쩡하던 기능을 망가뜨릴 때가 있다. GitHub에 버전별로 기록을 남겨두면, 문제가 생겼을 때 언제든 이전 버전으로 안전하게 복구할 수 있다.

① 출발: Gemini Argon에서 넘어온 5,400줄짜리 불완전한 파일

처음에 Gemini Argon으로 약 5,400줄짜리 HTML 파일을 만들었다. 3D 인형뽑기, 룰렛, 선물 도감이 들어 있는 야심 찬 앱이었지만 실행되지 않았고, 이 파일을 Claude에게 올리며 "정상적으로 작동하게 해줘"라고 요청했다.
Claude가 파일을 열어보니 용량 한계 등으로 인해 여러 군데가 심각하게 불완전한 상태였다.

  • 헤더와 엔진 누락: 파일이 밑도 끝도 없이 CSS 중간부터 시작했다. <head>, <style> 시작 부분, 그리고 가장 중요한 3D 엔진(three.js) 로드 코드가 통째로 빠져 있었다.
  • 변수 중복 오류: 같은 화면 코드가 옛 버전과 새 버전으로 두 번 들어 있어서 변수 중복 선언 오류가 났다.
  • 코드 뒤엉킴: 새로 추가된 코드가 엉뚱하게도 물리 엔진 함수 한가운데에 끼어 들어가 있었다.
  • 핵심 로직 증발: 집게 장치, 조작부(조이스틱, 버튼), 뽑기 판정, 물리 함수의 앞부분이 통째로 빠져 있었다.
  • 빈 화면 버그: 시작 버튼이 있는 인트로 화면 HTML 자체가 없어서, 실행하면 아무것도 없는 빈 화면만 나왔다.

💡 Claude의 해결: Claude는 잘려 나간 앞부분을 완벽히 복원하고, 빠져 있던 집게·조작·판정 로직을 남아 있는 코드의 변수 이름에 정확히 맞춰 역추적해 다시 만들어냈다. 중복된 코드도 깔끔하게 정리해 단숨에 작동하는 앱으로 살려냈다.

여기서 스크린샷이 엄청난 역할을 했다. 빈 베이지 화면 스크린샷 한 장 덕분에 "시작 버튼 HTML이 없다"는 원인을 즉시 찾았고, 알림창이 눈에는 보이지 않는(투명한) 상태에서도 화면 터치를 가로채서 홈·설정 버튼이 안 눌리는 황당한 버그도 스크린샷과 증상 설명만으로 정확히 잡아냈다.
물론 Claude도 실수를 했다. 한 번은 인트로 화면을 멋있게 바꾸다가 실수로 '당첨 연출 화면 HTML'을 지워버린 적이 있었다. 이건 내가 직접 폰으로 뽑기를 해보다가 "뽑았을 때 뜨는 화면이 이상하다"고 알려줘서 원인을 찾아 무사히 복원할 수 있었다.

PART 05 · 5 GOLDEN RULES OF AI CODING

💡 5. AI 코딩 200% 뽑아먹는 실전 요청 노하우 5가지

이번에 7,300줄짜리 앱을 만들면서 터득한, 코딩을 몰라도 AI에게 원하는 결과를 정확히 뽑아내는 5가지 핵심 법칙이다.

  • 1️⃣ @파일경로로 작업 대상을 정확히 찍어주기: 막연하게 말로만 설명하기보다 @파일이름.html로 파일을 직접 첨부(태그)하면, AI가 수천 줄의 기존 코드 구조와 변수명, 스타일을 먼저 다 읽고 시작하기 때문에 코드가 꼬이지 않는다.
  • 2️⃣ 요청 사항은 1, 2, 3... 번호를 매겨서 쪼개기: 긴 문장으로 줄글처럼 이어 쓰면 AI가 중간 요구사항을 빠뜨리기 쉽다. 버그 수정 / 삭제할 기능 / 바꿀 디자인 / 추가할 기능을 번호로 나누어 적으면, AI가 체크리스트처럼 하나도 빠짐없이 순서대로 처리한다.
  • 3️⃣ "어디가 어떻게 이상한지" 증상을 구체적으로 말하기:
    ❌ 나쁜 예: "인트로 좀 고쳐줘."
    ⭕ 좋은 예: "처음에 E3 글자 부분이 화면에 안 나와. 그리고 인트로가 살짝 느린 느낌이 있어서 더 빠르게 고쳐줘."
    실제 코드 원인은 몰라도 전혀 상관없다! 눈에 보이는 증상과 원하는 느낌만 정확히 말해주면 기술적인 원인(background-clip 충돌 등)은 AI가 알아서 찾아낸다.
  • 4️⃣ "기준이 되는 디자인"과 "원하는 색감/키워드" 찍어주기:
    ❌ 나쁜 예: "업적 창 예쁘게 바꿔줘."
    ⭕ 좋은 예: "업적, 뉴스, 설정 부분도 새로 바꾼 메인 허브처럼 멋있는 스타일(다크 퍼플 & 골드)로 통일해줘. 업적은 3D 배지나 트로피로 해주고, 재도전 보너스 알림창은 연한 파랑이나 초록색 느낌으로 다르게 해줘."
  • 5️⃣ 마지막에 "자율 기획 치트키 문장" 한 줄 넣어주기 (⭐가장 중요):
    프롬프트 맨 마지막에 "코드 수가 훨씬 더 늘어나더라도, 네가 생각하기에 필요하거나 감탄이 나올 정도로 엄청난 기능 넣을 거 있으면 넣어주고, 전체 UI/UX 통일성 생각해서 깔끔하고 고급스럽게 개선해 줘."를 넣어주면 AI가 코드 길이 제한 눈치를 보지 않고 3D 타로 행운 카드, 플레이어 랭크(LV) 시스템 같은 고퀄리티 기능을 스스로 기획해서 알아서 넣어준다.
